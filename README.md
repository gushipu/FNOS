# 飞牛 NAS 桌面客户端 2.0.0

面向飞牛 NAS（fnOS）的跨平台桌面客户端。以浏览器式的多标签容器承载 NAS 网页端，并在窗口层补齐下载、播放、直播、安全与集成能力：不用再在浏览器标签与桌面之间来回切换。

## 解决的问题

NAS 网页端把自己当成单页应用，从桌面点进 Docker、文件管理、影视等模块时会直接把当前页面替换掉，返回桌面需要反复点导航。本客户端在窗口层面接管导航：

- **桌面常驻**：首页始终占用第一个标签，不参与导航替换，也无法被关闭。
- **应用独立成页**：从桌面进入的任意模块都会在右侧新标签中打开，桌面标签保持原样。
- **导航拦截**：链接点击、`window.open`、整页跳转、单页路由（`pushState` / `replaceState` / hash 变化）四条路径全部纳入判断。
- **独立窗口模式**：可为单个应用创建桌面快捷方式，双击即以独立窗口直达该应用。

## 2.0.0 新增

- **多服务器独立会话分区**：每台 NAS 使用独立 `persist:fnos-<serverId>` 分区，多台设备的登录态互不覆盖，切换设备无需重新登录。
- **凭据加密存储**：登录口令由 `safeStorage` 加密落盘，索引密钥用 `scrypt` 派生，配置文件不再出现明文密码。
- **下载中心**：独立窗口集中管理全部下载任务，支持暂停 / 继续 / 打开文件 / 打开所在目录 / 移除 / 全部暂停 / 清空，任务状态实时刷新。
- **MPV 播放内核**：影视播放可切到 MPV 内核，自动探测本机或指定路径的播放器，支持自定义参数与路径选择。
- **电视直播**：内置直播窗口，支持多路 M3U 源、频道搜索与分组、收藏、EPG 节目单，播放内核可在内置播放器与 MPV 之间切换。
- **皮肤包**：支持导入 `.fskin` 皮肤包（配色 / 背景 / 圆角 / 字体），可切换与移除，实时生效。
- **锁屏与老板键**：可设置启动密码、空闲自动锁定、全局老板键一键隐藏或锁屏，密码支持修改与清除。
- **GPU 兼容模式**：显卡驱动异常的机器可关闭硬件加速与 GPU 合成，设置后重启生效。
- **应用快捷方式**：为当前设备或指定应用生成桌面快捷方式（Windows `.lnk` / macOS `.command` / Linux `.desktop`），带独立窗口参数。
- **全局快捷键**：8 个可自定义动作覆盖新建标签、关闭标签、刷新、恢复关闭的标签、下载中心、直播、锁屏等。
- **媒体嗅探**：自动识别页面中的媒体流，可一键交给下载中心或 MPV。

## 功能

- 多标签浏览：新建、切换、中键关闭、拖拽排序、右键菜单，`Ctrl+T` / `Ctrl+W` / `Ctrl+Tab` / `Ctrl+1…9` 快捷键
- 多设备管理：保存多个 NAS 地址，随时切换，启动自动连接默认设备
- 会话恢复：可选在启动时还原上次未关闭的标签
- 下载接管：网页下载直接写入指定目录，重名自动加序号，支持每次询问保存位置
- 主题跟随、托盘最小化（托盘菜单含下载中心与直播入口）、窗口位置记忆、版本检查（读取 GitHub Release）
- 无自绘标题栏干扰：Windows 使用原生窗口按钮，macOS 使用交通灯布局

## 开发

```bash
npm install
npm start
```

要求 Node.js 20 及以上、Electron 44。

## 打包

```bash
npm run dist:win   # Windows NSIS 安装包
npm run dist:mac   # macOS dmg（Apple Silicon）
```

产物输出到 `dist/`。

## 持续构建

推送 `v` 开头的标签即可触发 GitHub Actions 全流程：

```bash
git tag v2.0.0
git push origin v2.0.0
```

流水线依次执行脚本语法检查、Windows 与 macOS 双平台打包，并把安装包附到对应的 Release。

## 目录结构

```
src/
  main/        主进程：窗口与标签治理、配置与凭据、下载、MPV、直播、皮肤、锁屏、快捷键、快捷方式、更新
  preload/     预加载脚本：界面桥接、页面路由上报、页面内媒体嗅探
  renderer/    界面：主窗口、连接设备、设置、下载中心、电视直播
assets/        图标资源
build/         打包资源
.github/       持续集成配置
```
